📝 关键更新点 ​

1. OpenAPI JSON 接口说明 ​

强调点:

  • ✅ 直接返回标准 OpenAPI 3.0 格式
  • ✅ 不包装在 { success, data } 中
  • ✅ 使用 @SkipTransform() 装饰器实现
  • ✅ 符合 Apifox/Postman 导入要求

2. 技术实现细节 ​

核心机制:

typescript
// 1. 装饰器
@SkipTransform()
getOpenApiJson() { ... }

// 2. 拦截器检查
if (skipTransform) {
  return next.handle();  // 直接返回原始数据
}

// 3. 正常包装
return next.handle().pipe(
  map(data => ({ success: true, data }))
);

3. 使用指南 ​

Apifox 导入:

  1. 打开 Apifox
  2. 点击 "导入" → "URL 导入"
  3. 输入：http://localhost:3000/api/swagger/json
  4. 点击 "导入"
