🤝 贡献指南 ​

添加新文档 ​

  1. 确定文档类型，选择合适的子目录
  2. 使用清晰的文件命名（大写字母+下划线）
  3. 在本 README.md 中添加索引
  4. 提交时使用 docs: 前缀的 commit message

更新现有文档 ​

  1. 更新文档内容
  2. 更新文档顶部的"最后更新"日期
  3. 如有重大变更，在 CHANGELOG.md 中记录
  4. 提交时说明更新内容

📝 文档命名规范 ​

  • 配置文档: *_SETUP.md, *_CONFIG.md

  • 总结文档: *_SUMMARY.md, *_DELIVERY.md
