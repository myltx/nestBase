📝 文档编写规范 ​

文档命名 ​

  • 架构文档: 大写字母+下划线，如 API_NAMING_CONVENTION.md
  • 功能文档: 大写字母+下划线，如 LOGGING_SYSTEM_RELEASE.md
  • 指南文档: 大写字母+下划线或小写字母+连字符，如 CMS_API_GUIDE.md 或 users-module.md
  • 迁移文档: MIGRATION_ 前缀，如 MIGRATION_ADD_ICON_TYPE.md
